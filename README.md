# QA Workspace

Tracking taxonomy, validation rule, and QA workflow management application.

## Development

You need Node.js and npm.

```sh
npm i
npm run dev
```

AI 검증 규칙을 실행하려면 서버 환경에 `OPENAI_API_KEY`를 설정하세요. 모델은
`OPENAI_MODEL`로 바꿀 수 있으며 기본값은 `gpt-5.6-sol`입니다.

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
